プライバシーポリシー

制定日：2026年10月1日

坂下蓮治（以下「私」といいます）は、Mac で動くソフトウェア「Life OS」（以下「本ソフト」といいます）における情報の取り扱いについて、以下のとおり定めます。本ソフトは開発中で、いまは私自身だけが使っています。

1. 読む情報

本ソフトは、利用者の許可を得たうえで、Google の公式の仕組み（OAuth）を通じて次の情報を読みます。

Google ToDo リストリストと、その中のタスクの題・メモ・期日・完了したかどうか。メモを仕分けたリストへ移すため、書き込む許可も求めます。
Google カレンダー予定の題・日時・メモ欄。日付ではなく出来事を待つ予定を知らせるため、また予定を追加するため、書き込む許可も求めます。

2. 使い道

  • 予定とやることを整理し、時が来たものを利用者に知らせること
  • メモを分野ごとに仕分け、関係する記録と結びつけること

Google から受け取った情報を、広告、販売、利用者の信用の判断に使うことはありません。人がこれを読むのは、利用者本人だけです。

3. 保管する場所

読んだ情報と、仕分けの結果は、利用者の Mac の中のデータベースにだけ保管します。私が運営するサーバーはありません。

4. 外部のサービスへ送る場合

次の場合に限り、情報の一部が外部のサービスへ送られます。どちらも、送った内容で AI を学習しないと各社が定めています。

TypeSafe AI, Inc.（米国）メモを分野へ仕分けるために、メモの文章と分野の候補を送る場合があります。TypeSafe のプライバシーポリシー
Anthropic, PBC（米国）利用者が AI の Claude との会話で本ソフトの情報を読ませた場合、その部分が送られます。Anthropic のプライバシーポリシー

これ以外の第三者に、Google から受け取った情報を渡すことはありません（法令に基づく場合を除きます）。

5. Google API サービスのユーザーデータに関するポリシー

本ソフトが Google API から受け取った情報の利用と、他のアプリへの移転は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含みます）に従います。Google から受け取った情報を、汎用の AI のモデルの開発・改良・学習に使うことはありません。

6. 許可の取り消しと削除

利用者は、Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも本ソフトへの許可を取り消せます。取り消した後、Mac の中に保管した情報の削除を求められた場合は、削除します。

7. 本ポリシーの変更

必要に応じて本ポリシーを変更することがあります。変更後の内容は、本ページに掲載した時点から効力を生じます。
